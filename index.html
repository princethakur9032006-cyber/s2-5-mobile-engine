Known MVP limits

This is a working starter renderer, not a full clone of the tutorial's proprietary setup. It builds procedural 3D sets and simple 2D-like cartoon characters. It does not yet create sophisticated character rigs, AI-generated textures, automatic voice synthesis, or guaranteed MP4 output. Android Chrome usually records WebM; convert it to MP4 in Canva if needed. Three.js is loaded from a free public CDN, so the first load requires internet.
